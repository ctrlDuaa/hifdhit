# Hifdh It
A personalized Qur’an memorization platform built to make hifdh accessible, structured, and meaningful for every Muslim.

## Overview
Hifdh It is an adaptive Qur’an memorization app designed to help users learn, retain, and review verses independently, whether they are memorizing a few meaningful ayat, preparing surahs for Salah, or pursuing full hifdh.
While many existing hifdh tools are built primarily for advanced students, Hifdh It was created to support all Muslims, including those memorizing casually or independently without a teacher or study partner.
The app combines guided memorization, adaptive review, mistake tracking, and Quran.com integration to create a personalized memorization experience that helps users build long-term retention and a deeper connection with the Qur’an.

# Key Features
**Guided Memorization**
Users memorize through an interactive flow where words gradually disappear, encouraging active recall instead of passive repetition.
**Adaptive Review Engine**
After every memorization or review session, Hifdh It uses user feedback, mistake count, and mistake type to determine how often each passage should be reviewed, creating a fully personalized revision schedule.
**Mistake Tracking by Type**
Users can mark mistakes as:
- Incorrect
- Missed
- Tajweed
- Forgot
This helps identify specific weaknesses and improve intentionally.
**Mushaf Revision Mode**
Users can revisit pages where mistakes were made directly in a digital Mushaf layout, with color-coded mistakes, personal notes, and familiar page positioning. This supports stronger visual and spatial memory.
**Collaborative Sessions**
Users can revise together in real time, allowing one user to listen and mark mistakes while the other recites, bringing the accountability of in-person revision online.
**Self-Guided Tools**
To support different memorization styles, users can:
- record and replay their own recitation
- use a built-in repetition counter for traditional repetition-based memorization
**Progress Insights**
Track consistency, improvement, and memorization progress across the Qur’an over time.
**Meaningful Engagement**
Users can bookmark verses that resonate with them and later explore them more deeply on Quran.com through Tafsir, Hadith, Contextual insights, and more!

## Quran.com API Integration
Hifdh It uses both Content APIs and User APIs from Quran.com.
**Content APIs**
Verses API: display Qur’an verses
Chapters API: browse/select Surahs
Page Layout API: authentic Mushaf positioning
Audio API: recitation playback
Translation API: meaning alongside memorization
**User APIs**
via OAuth Authentication
Collection: import saved verse collections
Bookmarks: save meaningful verses
User Preferences: personalized reciter, translation, and language

## Goal
Hifdh It is more than a memorization app.
It is a personalized hifdh companion built to make memorizing the Qur’an more accessible, more structured, and more sustainable, so that every Muslim, regardless of where they are in their journey, can build a lasting relationship with the Qur’an.
